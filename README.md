# SimpleFC plug-in for NSIS

![Release](https://img.shields.io/github/v/release/nsis-community/plugin-simplefc?style=for-the-badge)
![CI](https://img.shields.io/github/actions/workflow/status/nsis-community/plugin-simplefc/ci.yml?style=for-the-badge)

This repository mirrors the SimpleFC plug-in, which was previously hosted on the [NSIS wiki](https://nsis.sourceforge.io/). Its source has been rearranged so that it builds automatically; code changes are limited to build fixes.

**Are you the author?** You're welcome to take it over: [open an issue](https://github.com/nsis-community/plugin-simplefc/issues/new) and we'll transfer the repository to you.

> [!NOTE]
> **Looking for the usage guide?** See [Docs/SimpleFC/Readme.txt](Docs/SimpleFC/Readme.txt).

## Installation

Download the installer or archive from the [Releases page](https://github.com/nsis-community/plugin-simplefc/releases).

If you downloaded the zip archive, extract it into your NSIS folder: it adds `SimpleFC.dll` to `Plugins/<variant>/`.
